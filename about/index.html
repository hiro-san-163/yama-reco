このサイトについて

ようこそ、hiro-sanの山歩きへ。

学生時代に山に親しみ、五十代半ばでランニングから山歩きへと移りました。 このサイトでは、その時々の山行を記録として残しています。

ワンダーフォーゲルという言葉に惹かれ、山を登るだけでなく、 沢歩きや街道歩き、古道歩きなど、歩く過程そのものを楽しんでいます。

本サイトの山行記録は概要のみを掲載しています。 詳細については、各記事からブログやヤマレコをご覧ください。

```
```

山との関わり

瀬戸内の島で育ち、子どもの頃は海のある風景が当たり前でした。 当時は、海の見えない場所で暮らすことなど想像もしていませんでした。

学生時代、目の前にそびえる石鎚山に圧倒され、 ワンダーフォーゲル部に入りました。

その後、仕事や子育てを経て、自分を見つめ直す時間の中で、 再び山歩きを始めました。

山との関わりは、マラソンやウルトラマラソンから トレイルランニングへと移り、 長い距離を移動する楽しさから始まりました。

ソロでの山行からグループ山行へ、 そして現在は山岳会での活動も行っています。 無理のない範囲で、長く歩き続けることを大切にしています。

```
```

名前の由来

「hiro-san」という名前は、 子どもの頃におば（母の姉）からそう呼ばれていたことに由来しています。
