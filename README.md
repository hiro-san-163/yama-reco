# hiro-san 山歩きサイト V5

## 概要

個人の山行記録サイト。

GitHub Pages + Jekyll で運用する。

## 基本方針

- GitHub Pages標準環境で動作
- プラグイン非依存
- データ駆動型設計
- 検索機能重視

## 開発方針

本プロジェクトは設計優先で開発を行う。

既存V5アーキテクチャの範囲で実装すること。

仕様変更が必要な場合は実装を行わず、

- 変更理由
- メリット
- デメリット
- 影響範囲

を整理した上で提案を行うこと。
